Clear rule: Maintenance = property upkeep (plumbing, electrical, security, interior); Professional = advisory/profession-based (surveying, legal, advisory) — not property maintenance.

### B. Admin — Service Category Configuration Overhaul
Current "Add Category" form (Name, Slug, Tagline, Description, Sort Order) is too basic. Rebuild as a multi-section configurator (~12 configurable aspects) per category:

1. **Basic Info**
   - [ ] Name, Category type (Maintenance / Professional), Description, Icon, Status (Active/Inactive)

2. **Delivery Strategy** (per-service, admin-selectable mode)
   - [ ] Mode: `Internal` (staff-only) / `Managed` (partner firm, e.g. revenue-share 10–30%) / `Marketplace` (open provider marketplace)
   - [ ] Support assigning a specific provider/firm as "Internal" or "Managed" partner
   - [ ] Keep this flexible/extensible — not hardcoded to 3 fixed modes long-term

3. **Visibility Rules**
   - [ ] Per-role visibility toggles: Tenant, Landlord, Property Manager, Agency, Developer, Staff, etc.

4. **Availability Rules**
   - [ ] System-level default time-window rule (e.g. block plumbing 11pm–X, allow consultation anytime)
   - [ ] Allow per-provider override of their own availability within the default rule

5. **Priority / Routing Rules**
   - [ ] Default ordering when multiple delivery strategies apply: Internal → Managed → Marketplace
   - [ ] Secondary tie-breakers: rating, proximity, provider availability, etc.

6. **Approval Rules**
   - [ ] Toggle whether a request requires approval, and from whom (Landlord / Tenant / Property Manager)

7. **Quotation Rules**
   - [ ] Toggle whether quotation step is required per service

8. **Payment Rules**
   - [ ] Configurable per service: Escrow-only, Invoice-after-completion, or Subscription (monthly)

9. **Assignment Strategy**
   - [ ] Options: Automatic, Manual, Nearest Provider, Least Busy, Customer Choice

10. **SLA / Requirements**
    - [ ] Configurable provider requirements: license, credentials, documents — set as sensible defaults but overridable per service (system must not be rigid)

11. **Automation Rules**
    - [ ] Post-completion automations: request rating, notify property manager, notify accounts, update reputation/"preparation" score, issue invoice, and similar triggers — all configurable by admin

12. **Review/Consistency Check**
    - [ ] Ensure no Maintenance-type service ever appears inside Professional Services list (and vice versa) once configured.

### C. Cross-Cutting Goal
